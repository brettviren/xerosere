## Overview

This provides a Python package with CLI entry named `xerosere` to help
initialize and manage a software development area based on a Spack Environment
View directory (and soon based on a pixi env).  More information is in README.org.

## Issues and tasks

This project uses **bd (beads)** for issue tracking and task planning.

### Quick Reference

```bash
bd ready              # Find available work
bd show <id>          # View issue details
bd update <id> --claim  # Claim work
bd close <id>         # Complete work
```

### Rules

- Use `bd` for ALL task tracking — do NOT use TodoWrite, TaskCreate, or markdown TODO lists
- Run `bd prime` for detailed command reference and session close protocol
- Use `bd remember` for persistent knowledge — do NOT use MEMORY.md files
